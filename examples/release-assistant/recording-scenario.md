# Сценарий видео — домашка 35

Формат: настоящий TUI DeepSeek Client, автоматизированная навигация через
временный Go build overlay. Во всех сценах видна пометка о сохранённом реальном
прогоне. Новых API-запросов нет. Ответ DeepSeek загружается из `tui-answer.json`,
проходит через обычные TUI submit/update; это просмотр результата, не новая генерация.
Основной код приложения для записи не меняется.

| Время, примерно | Сцена | Что доказывает |
|---|---|---|
| 00:00–00:14 | Реальная задача | Подготовка релиза собственного DeepSeek Client; проблема и решение |
| 00:14–00:26 | Цель пользователя | Запрос на уровне результата; обычный и бесплатный способы запуска |
| 00:26–00:44 | Git | Во время записи заново читаются реальные коммиты w6-hw5 → w7-hw4; показаны конкретные SHA |
| 00:44–01:04 | Проверки | Сохранённые реальные Go/Node/Python результаты из снимка кандидата, границы проверки |
| 01:04–01:26 | RAG | Реальный выбранный источник из input.json; корпус и выборка для модели |
| 01:26–01:46 | DeepSeek | Сохранённый реальный ответ в TUI: изменения, настройка и риски с цитатами |
| 01:46–02:04 | Артефакты | Файлы результата и повторная проверка 11 SHA-256 прямо во время записи |
| 02:04–02:22 | Ошибка проверки | Сохранённый негативный прогон: Node недоступен, exit 1, blocked, без AI |
| 02:22–02:36 | Итог | Требования домашки, ручное ревью, бюджет и расположение результата |

Чтение Git и проверка хешей выполняются заново. Тесты и запросы к DeepSeek
не повторяются: показаны их сохранённые результаты. Успешный запуск сохраняет
`manual_review_required`, не публикует релиз и не создаёт тег.

Ограничения: подборка RAG не равна полному AI-аудиту diff. Точные короткие цитаты
не доказывают полноту составных утверждений; инструкции из старой документации
требуют проверки актуальности. Запись без озвучки; пояснения находятся на экране.
