# Ассистент разработчика: DeepSeek Client о собственном проекте

## Запуск

Из корня монорепозитория:

```powershell
./Start-Developer-Assistant.ps1
```

Также доступен Start-Developer-Assistant.cmd для запуска двойным щелчком.
Используется обычный API-профиль клиента, но отдельные история и память.
Если выбран другой профиль, переключитесь на /profile deepseek.

В TUI:

```text
/help Как устроен проект? За что отвечает пакет agent?
/help Где добавлять новый Git MCP-инструмент?
/help На какой git-ветке мы сейчас работаем?
/help Какие поля содержит доказательный ответ модели?
```

Для подготовки без генерации: ./Start-Developer-Assistant.ps1 -PrepareOnly.
После изменения README/docs: ./Start-Developer-Assistant.ps1 -Rebuild.
-Python и -ModelCache позволяют использовать другое готовое локальное RAG-окружение.
Launcher не скачивает модели и не меняет обычную конфигурацию API.
Нужны Go, PowerShell 7, Ollama с nomic-embed-text:latest и готовый Python-кэш.
После /new выберите проектную базу через /kb; исходный диалог её получает при старте.

## Что подключено

- README.md проекта и три актуальные страницы projects/deepseek-client/docs.
- Реальные локальные эмбеддинги nomic-embed-text:latest, Qdrant Local и reranker.
- Локальный Git MCP по stdio, без HTTP-порта и токена.
- Файловый workspace ограничен projects/deepseek-client; Git относится к монорепозиторию.
- Перед каждым привязанным вопросом /help выполняется фиксированный git__git_status.
  В доказательства попадает только заголовок ветки, без списка изменённых файлов.
- Runtime-источник mcp://git/git_status отделён от документов и не получает
  искусственных similarity/reranker scores.
- Проверяются цитаты из обоих видов источников. /help допускает только чтение.
- Выбранная база должна содержать README и docs этого проекта.
- Историческая docs/llm-wiki, private user config, raw и wiki в корпус не включены.

Индексы и состояние находятся в Git-ignored .project-assistant.
SHA256 источников проверяется при запуске: устаревший корпус требует -Rebuild.
Каждая перестройка получает новую папку; старый индекс сохраняется.
Обычная конфигурация API читается стандартным клиентом, секреты не копируются в корпус.

## Воспроизведение проверки

Обычные проверки не вызывают API:

```powershell
go test ./projects/deepseek-client/...
go vet ./projects/deepseek-client/...
go build ./projects/deepseek-client/...
```

Опциональный TestProjectAssistantTUI в project_assistant_integration_test.go требует
явного PROJECT_ASSISTANT_LOCAL=1 или PROJECT_ASSISTANT_PAID=1, уникальной папки
вывода, пути к собранному бинарнику и текущему index.json. Paid-режим дополнительно
требует текущего разрешения, PROJECT_ASSISTANT_BUDGET_USD=0.20 и общего ledger.
Журнал резервируется до каждого API-вызова; повторные прогоны используют тот же
ledger. Лимиты: 60000-byte envelope, 10 API-вызовов суммарно и максимум два на вопрос.

Сбой обязательного MCP блокирует запрос до генерации. Чужая база не подмешивается.
Проверка цитат не заменяет содержательную оценку и доверие к настроенному серверу.
