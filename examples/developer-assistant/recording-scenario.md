# Сценарий видео — домашка 31: ассистент разработчика

Формат: примерно 2–3 минуты, без звука. Настоящий TUI, реальные retrieval/MCP
и DeepSeek. Ввод автоматизирован; временный full-frame renderer показывает
обычный TUI View без подмены ответов и без изменений продуктового кода.

| Этап | Действие | Что доказывает |
|---|---|---|
| Вступление, 14 секунд | Показать выбранную базу: README и три docs-страницы | Документация подключена через RAG |
| Структура проекта | /help Как устроен проект? За что отвечает пакет agent? | Ответ на вопрос о проекте с цитатами и doc-источником |
| Ветка | /help На какой git-ветке мы сейчас работаем? | Свежий Git MCP и отдельный источник mcp://git/git_status |
| Нет подтверждений | /help Какой порт использует PostgreSQL-база нашего проекта? | unknown без выдуманного порта |
| Итог, 14 секунд | Показать выполнение требований и результат предварительной проверки | Отдельно обозначить: видео содержит три вопроса, полная проверка — пять |

Перед отправкой каждого вопроса пауза 6 секунд. После ответа 26 секунд:
первая половина — начало ответа, вторая — цитаты и источники.
Итоговая длина зависит от времени реальных API-запросов.

Безопасность: отдельная история, инструменты только чтения, захват только
выделенного окна, ключи не отображаются. Для записи планируются три новых
API-вызова с документацией проекта и текущей веткой. Они учитываются в общем
ledger бюджета $0.20 вместе с предыдущей проверкой.
На момент подготовки: 5 прошлых вызовов, reserve $0.0291294,
оценка peak usage $0.004355448.

Готовность и результат: индекс, модели и MCP подготовлены до записи;
screenshot OBS проверен. После отдельного подтверждения пользователя выполнены
ровно три новых живых запроса в рамках общего бюджета $0.20.
Видео записано, проверено полным decode и кадрами, сцена/звук OBS восстановлены.
