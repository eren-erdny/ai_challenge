# Сценарий видео домашки 34

Формат: настоящий TUI DeepSeek Client, автоматизированная навигация и повтор
сохранённого реального журнала инструментов на новой рабочей копии TaskDesk.
На каждом экране подписано: это повтор, новых запросов модели нет.
Модель выбрала операции в ранее выполненном живом прогоне; во время записи
чтения, поиск, правки и создание файла выполняются заново настоящим executor.

| План | Сцена | Видимое подтверждение |
|---|---|---|
| 0:00–0:08 | Введение | Две цели, исходные файлы, границы записи |
| 0:08–0:16 | Цель 1 | Задача привести документацию в соответствие с кодом |
| 0:16–0:34 | Исследование | list/find/read, код правил экспорта, устаревшие утверждения |
| 0:34–0:56 | Правки | edit_file, реальные README и FAQ после записи |
| 0:56–1:04 | Цель 2 | Найти использования API и создать карту |
| 1:04–1:22 | Поиск | Параметры search_text, прочитанные API/UI, цепочка вызовов |
| 1:22–1:44 | Создание | write_file/read_file, фрагмент реальной карты API |
| 1:44–2:06 | Diff | Изменения из фактических байтов до/после |
| 2:06–2:22 | Проверки | Совпадение с живым прогоном, 7 Node-тестов, код сохранён |

Записано и проверено: 143.75 секунды, 2560×1440, 60 fps.
Точное время сцен и проверка готового файла сохранены в obs-recording.json.

Для сценария использована временная Go build overlay: физические исходники
приложения не изменялись. Overlay использует настоящий tuiModel и его View,
а файловые операции — fileassistant.Session и существующий filetools.Documents.
Полная перерисовка консоли нужна для стабильного захвата OBS. Это не новый
самостоятельный прогон модели и не подмена ответов провайдера.

Ключи, конфигурация и личные переписки не загружаются. Полный сохранённый журнал
доступен в tool-trace.json; исходный реальный результат — verification.json.
Для повторения операций API не требуется. Тесты во время записи запускаются
отдельным проверяющим кодом; shell-инструмент модели не предоставляется.

Имя результата: ai_challenge_hw34.mp4. Озвучка не добавляется.
