# TaskDesk — продукт

TaskDesk — вымышленный сервис управления задачами для демонстрации поддержки.
Тариф Free включает задачи и экспорт CSV. Тариф Pro дополнительно включает экспорт PDF.
Поддержка использует FAQ и данные только выбранного пользователя и его тикета.
Пароли, токены и платёжные реквизиты не нужны для диагностики.
