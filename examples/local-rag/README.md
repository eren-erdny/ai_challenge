# День 28. Полностью локальный RAG

Используется обычный DeepSeek Client, профиль `ollama_rag`, модель `qwen3.5:4b-rag` (Qwen 3.5 4B).
Retrieval: сохранённый индекс `artifacts/hw21/index.json`, Qdrant Local,
локальные `nomic-embed-text:latest` embeddings и CPU cross-encoder reranker.
Генерация: Ollama `http://127.0.0.1:11434/v1`, API-ключ не нужен.
Профиль: контекст приложения 16384, максимум ответа 2048, temperature 0,
reasoning_effort none. [Modelfile](Modelfile) отдельно задаёт реальное окно Ollama 16384; соответствие проверяет интеграционный тест.

## Запуск обычного приложения

Запустите [Start-Local-RAG.cmd](../../Start-Local-RAG.cmd). Он собирает обычный
клиент, прогревает Qwen и использует отдельные настройки/историю в
`.local-llm/rag-appdata`. Если Qwen отсутствует, launcher скачает её.
Готовые Python и кэш можно указать параметрами
[Start-Local-RAG.ps1](../../Start-Local-RAG.ps1):

```powershell
./Start-Local-RAG.ps1 -Python 'PATH/python.exe' -ModelCache 'PATH/models'
```

Нужны Go, Ollama, уже подготовленное RAG-окружение с зависимостями и локальный
кэш tokenizer/reranker. HF_HUB_OFFLINE и TRANSFORMERS_OFFLINE включены launcher.
Первоначальная установка Qwen требует сети; inference после подготовки локальный.

В клиенте: **F2 → 7 → полный путь к artifacts/hw21/index.json**. Индекс открывается
без перестройки. Для обычного профиля пользователя также доступно
`/profile ollama_rag` (добавлен с сохранением других профилей и текущего выбора).
Выбор модели в сессии не переписывает конфигурацию автоматически. Другие
профили остаются доступными; firewall или сетевые настройки не менялись.

Оставьте retrieval включённым: `/tools off` отключает и его. Запросите, например:

```text
May HTTP 429 responses include a Retry-After header?
May HTTP 431 responses be stored by a cache? Preserve the normative requirement.
What is the distance from Earth to the Moon?
```

На экране видны локальная модель, база, найденные фрагменты, ответ, цитаты и
`source#chunk_id`. Пустая выдача даёт локальное «не знаю» без вызова генерации.
Невалидные JSON или цитаты отклоняются до показа и сохранения.

## Проверка и сравнение

Десять прежних [контрольных вопросов](../rag-grounding/questions.json), два
независимых локальных прогона без истории. Каждый turn вызывает настоящий
retrieval через production manager и настоящий HTTP adapter. Дополнительный
preflight-поиск сохраняет выдачу для zero-call вопроса и прогревает runtime;
он не заменяет поиск внутри обычного TUI. Время total_seconds относится к
реальному TUI turn; API Duration — только к HTTP генерации. Startup измерен
отдельно, первый model load может входить в первую генерацию.

Облачное сравнение использует [ранее сохранённые реальные ответы DeepSeek](../rag-grounding/answers.json)
и [их ручную оценку](../rag-grounding/answer-review.json). Новых облачных или
платных вызовов нет. Сравнение не является одновременным benchmark: отличаются
даты, модели, tokenizer, лимиты и уточнённая локальная инструкция. Скрипт
отдельно проверяет совпадение найденных текстов/chunk_id. Повторяемость облачной
модели по одному сохранённому прогону не измерена.

[Сравнение качества, скорости и стабильности](comparison.md),
[числа и полная таблица](comparison.json), [ручная оценка](answer-review.json),
[ответы финальной проверки](context-verification-20261010/answers.json).
Формальная проверка происхождения цитат не доказывает логическое следование:
каждое утверждение дополнительно просмотрено относительно прикреплённых цитат.

Предварительные прогоны сохранены: Gemma с JSON-mode в `verification-20261010`,
Gemma без принудительного формата в `profile-verification-20261010`, Qwen с
первоначальной многословной инструкцией в `qwen-verification-20261010`.
Дополнительный незавершённый `final-verification-20261010` — уточнённая инструкция при старом runtime context 4096.
Они не выдаются за финальную проверку. Финальный каталог — `context-verification-20261010`. Gemma IQ3 портила JSON; отключение JSON-mode
не помогло, и экспериментальная настройка удалена. Qwen иногда меняла цитаты
и добавляла соседние факты. Общая инструкция уточнена: минимум необходимых
утверждений, прямое подтверждение каждого, без повторов и соседних фактов.

Офлайн-перепроверка без новых вызовов:

```powershell
python examples/local-rag/report.py
cd projects/deepseek-client
go test ./...
go vet ./...
```

Для нового локального прогона задайте HW28_LOCAL_TEST=1, новую HW28_OUTPUT,
DEEPSEEK_RAG_PYTHON и DEEPSEEK_RAG_MODEL_CACHE; запускайте
`go test -run '^TestHomework28LocalRAG$' -count=1 -v .`.
HW28_INDEX позволяет явно выбрать другой готовый совместимый индекс.
Существующие результаты не перезаписываются.
