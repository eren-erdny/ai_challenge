# День 25: план мини-чата с RAG и памятью

1. Продолжить существующий CLI/TUI: JSON-история и поиск по выбранной базе на каждом вопросе.
2. Добавить `/brief`: цель, тема, ограничения, термины и уточнения. Память задаёт пользователь;
   она отдельна для каждого чата, переживает перезапуск и ограничение окна истории.
3. Для коротких продолжений использовать явные термины и предыдущую тему в запросе поиска.
   В LLM поступает исходный вопрос; подтверждения берутся только из новой выдачи.
4. Всегда показывать источники; для «не знаю» явно показывать отсутствие подтверждений.
5. Проверить команды, исправления, изоляцию чатов, перезапуск, sliding window и отказ от старых цитат.
6. Два сценария по 12 вопросов с настоящим DeepSeek: HTTP API и HTCPCP-TEA.
   Заранее зафиксировать ожидания и источники; сохранять ответы, выдачу и снимки памяти.
7. Проверить происхождение всех цитат и смысл утверждений; отдельно оценить сохранение цели.
8. Подготовить 2–3-минутный OBS-сценарий с живыми продолжениями и итогом полного прогона.
   Общий бюджет проверки/записи до $0.20, без дополнительных моделей и повторов для репетиции.
9. После проверки и записи создать коммит и тег `w5-hw5` в `week-5` и опубликовать их.

Это расширение обычного чата, а не переключение в lifecycle-режим `/mode task`.
Память задачи не считается доказательством фактов из документов.
