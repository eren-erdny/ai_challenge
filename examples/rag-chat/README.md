# День 25: мини-чат с RAG и памятью задачи

Продолжение обычного CLI/TUI клиента: выберите базу через F2, задайте цель
и ограничения через `/brief`, задавайте вопросы. Каждый вопрос делает новый
поиск, а ответы содержат проверенные цитаты и источники. JSON-история и память
сохраняются локально для каждого чата и восстанавливаются при запуске.

```text
/conversation http-api
/brief goal Составить чек-лист кодов ответа HTTP API
/brief constraint style На русском, не более двух коротких утверждений
/brief term signal HTTP 429 Too Many Requests
/brief clarify scope Только выбранная база
Что означает signal?
Можно ли его кэшировать?
/brief term signal HTTP 431 Request Header Fields Too Large
Что теперь означает signal?
/brief
```

[Все команды и ограничения](../../projects/deepseek-client/RAG.md),
[план](PLAN.md), [сценарии с ожиданиями и источниками](scenarios.json).
Память задаёт пользователь явно; автоматического извлечения из разговора нет.
Она отделена от жизненного цикла `/mode task` и не служит доказательством фактов.

Два сценария по 12 настоящих запросов DeepSeek: HTTP API и HTCPCP-TEA.
Поиск выполнялся на каждой реплике; после шестой реплики переоткрывались
JSON-хранилища и TUI. Даже с окном в 4 сообщения цель и ограничения оставались
в запросах. Проверены исправление терминов и изоляция между чатами.
24/24 ответа имеют источники и цитаты; 29 утверждений поддержаны 29 точными
цитатами. 23/24 ожидания покрыты полностью, один ответ частичный.

Повторная независимая проверка сохранённых результатов **без API**:

```powershell
python examples/rag-chat/report.py
cd projects/deepseek-client

```

Опциональный тест `TestHomework25LongConversations` по умолчанию пропущен.
`HW25_LOCAL_TEST=1` включает реальный локальный поиск с явно обозначенной
fixture-генерацией. Для него нужны `HW25_OUTPUT` с копией scenarios.json,
новый `HW25_STATE_DIR`, `HW25_CORPUS` и подготовленные модели/Python через
`DEEPSEEK_RAG_PYTHON`, `DEEPSEEK_RAG_MODEL_CACHE`.
Платный режим требует `HW25_PAID_TEST=1` и текущего разрешения/бюджета,
`HW25_BUDGET_USD` до $0.20; расходы предыдущих попыток учитываются через
`HW25_EARLIER_REPORT`. Не запускайте его для просмотра результатов.

История сохраняется полностью; окно ограничивает только отправляемый контекст.
Команды `/brief` используют working memory `brief.*` и не вызывают модель.
Корректность происхождения цитат не является универсальной проверкой смысла.
Для неподтверждённого ответа выводятся «не знаю», уточнение и явный статус
отсутствия источников. Сохранять или показывать неподходящие источники нельзя.
