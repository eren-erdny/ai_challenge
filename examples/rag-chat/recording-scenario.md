# Сценарий OBS: день 25

Около 2–3 минут, настоящий BubbleTea TUI и DeepSeek Flash. Автоматизированный
ввод и временные страницы пояснений/фактических ответов обозначены в начале.
Без личной истории: изолированная копия двух публичных проверенных чатов.
Индекс и модели прогреты до записи; платной репетиции нет.

| Этап | Наблюдаемое доказательство |
|---|---|
| Начало и `/brief` | HTTP-цель, ограничения, уточнения и термин в длинном чате |
| Изменение `signal` | Явно записать 429, затем 431; новое определение видно через `/brief` |
| What does signal indicate now? | Новый реальный ответ о 431, текущий поиск, цитаты и источники |
| Can it be stored by a cache? | Продолжение относится к 431, новый поиск, MUST NOT |
| Восстановление | Переоткрыть JSON stores и TUI внутри процесса; 28 сообщений, цель и термин сохранены |
| `/conversation tea-checklist` | Другая цель, термин device, отсутствие signal |
| Выбор кода для кофе | Условие not provisioned; 503 temporary или 418 more permanent; источник RFC7168 |
| Вопрос о Луне | Пустой контекст, локальное «не знаю», уточнение и явный статус источников, 0 LLM-вызовов |
| Итог | Отдельная сводка ранее выполненных 2×12 вопросов; 23 полных ожидания и один частичный ответ |

Восстановление внутри процесса не называется перезапуском ОС. Полный набор не
повторяется ради записи. Временная оболочка не меняет ответы или решения модели;
показывает их текст и цитаты на удобных для чтения страницах.

Общий текущий бюджет $0.20 включает первый неудачный прогон, исправленную
проверку и три новых одиночных API-вызова записи. Верхний резерв до записи
$0.1583271. Максимум 20K входных UTF-8 байт с запасом и 768 выходных токенов;
резерв проверяется до каждого вызова, thinking disabled, без инструментов,
дополнительных моделей и автоматических повторов.
