# Запись OBS: день 25

[ai_challenge_hw25.mp4](C:/Users/erdni/Videos/ai_challenge_hw25.mp4) — **2 минуты 43 секунды**,
2560×1440, 60 fps, без озвучки. Полный декодер завершился с кодом 0; просмотрены
13 кадров из закодированного видео. [Сценарий](recording-scenario.md) подготовлен заранее.

Настоящий BubbleTea TUI и DeepSeek Flash. Ввод автоматизирован событиями TUI;
временная оболочка показывает пояснения и страницы фактических результатов.
Изолированная копия публичных тестовых чатов; личная история не использовалась.
Индекс пересоздан локально перед записью, поскольку backend привязывает его к пути.

| Пример | Проверенный результат |
|---|---|
| Изменение signal 429 → 431 | Последнее определение записано через /brief; цель/ограничения видны |
| What does signal indicate now? | Причина 431 и MAY-повторение после уменьшения заголовков; 2 точные цитаты |
| Can it be stored by a cache? | Новый поиск с предыдущей темой; 431 MUST NOT кэшироваться; источник RFC6585 |
| Восстановление | Переоткрытые JSON stores и модель TUI внутри процесса: 28 сообщений HTTP, цель и signal сохранены |
| Другой чат | tea-checklist имеет другую цель и device, без signal; независимая память |
| Неподготовленный к кофе чайник | Условие not provisioned, 503 temporary или 418 more permanent; RFC7168, цитата и section/chunk_id |
| Вопрос о Луне | 0 чанков, локальное «не знаю», уточнение, явный статус отсутствия источников; 0 LLM-вызовов |

Все 4 новых утверждения проверены по связанным цитатам и разделам, все 4 цитаты
точно совпадают с текущими чанками. Это конечная проверка, не гарантия смысловой
корректности любых будущих ответов. Память /brief заполняет пользователь явно.

Итоговый экран отделяет прежние 2×12 вопросов (24 ответа, 29 проверенных цитат,
23 полных ожидания и один частичный ответ) от записи (4 вопроса, 3 новых платных вызова).
SHA-256 прежнего answers.json проверен перед показом. [Новые ответы и выдача](recording-comparison.json),
[проверка смысла](recording-review.json), [техническая проверка](obs-recording.json).
