# День 24: проверяемые ответы по базе

Вариант: один ответ модели в JSON + локальная проверка происхождения цитат.
Данные: публичные RFC из `../rag-indexing/corpus`, индекс дня 21. Новый индекс
и новый набор источников не требуются.

- `questions.json`: 6 обычных вопросов, отрицание, условие/альтернативы,
  2 вопроса без подтверждения; ожидания, источники, разделы и эталонные фрагменты.
- `retrieval.json`: реальный локальный поиск, без платной генерации.
- `answers.json`: 10 реальных TUI-команд клиента, 9 вызовов DeepSeek;
  raw JSON, выдача, проверенная структура, видимый ответ и учёт бюджета.
- `answer-review.json`: содержательная проверка каждого утверждения с привязкой
  к цитатам; SHA-256 защищает от применения оценки к изменённому прогону.
- `comparison.md`, `stats.json`: проверка и отчёт, воспроизводимые без API.
- `local-integration.json`: отдельная проверка управления базами с настоящим
  локальным поиском и тестовой генерацией, без DeepSeek.

```powershell
# Только локальный поиск; нужен установленный и запущенный Ollama.
python examples/rag-grounding/prepare.py --model-cache PATH_TO_EXISTING_CACHE
# Независимая перепроверка сохранённых цитат, источников и ручной оценки.
python examples/rag-grounding/report.py
```

Опциональный платный тест находится в `knowledge_hw24_test.go`.
Он запускается только при `HW24_PAID_TEST=1` и текущем разрешённом бюджете
`HW24_BUDGET_USD` до $0.20. Также нужны `HW24_OUTPUT`, `HW24_CORPUS`,
`DEEPSEEK_RAG_PYTHON` и `DEEPSEEK_RAG_MODEL_CACHE`. Запуск из модуля клиента:
`go test . -run '^TestHomework24RealDeepSeek$' -count=1 -v`.
Существующий `answers.json` не перезаписывается; для нового прогона нужна
новая выходная папка с `questions.json`. Исторический бюджет не разрешает
новые вызовы. Секреты берутся из локальной конфигурации и не записываются.

Для содержательных ответов источники и цитаты обязательны. Для `unknown`
списки пустые: нерелевантная цитата не должна выглядеть как доказательство.
Валидатор подтверждает происхождение цитаты и связь с утверждением, но не
проводит логическую проверку смысла. На сохранённом наборе смысл всех
16 утверждений проверен отдельно; дополнительная модель-судья не использовалась.

Исходный прогон на 10 вопросах проверял реальный TUI-код автоматическими
командами без OBS. Затем записана отдельная демонстрация на 4 вопросах:
[сценарий](recording-scenario.md), [отчёт](recording.md),
[новые результаты](recording-comparison.json), [проверка видео](obs-recording.json).
