# День 27: Ollama как профиль обычного DeepSeek Client

Локальная модель подключена к существующему CLI/TUI приложению через обычный
OpenAI-compatible профиль `ollama_local`. Отправка запросов и отображение ответов
используют стандартные `executeQuestion`, agent и `askDeepSeek` / HTTP adapter.

В обычном клиенте выберите:

```text
/profile ollama_local
```

Профиль уже добавлен в пользовательские настройки, другие профили и текущий
выбор сохранены. Публичный образец:
[config.example.json](../../projects/deepseek-client/config.example.json).
Адрес — `http://127.0.0.1:11434/v1`; модель — `batiai/gemma4-12b:iq3`;
API-ключ не требуется, `reasoning_effort=none`. Профиль можно выбирать обычной
командой; выбор сохраняется в текущей сессии, конфигурация автоматически не
переписывается. Другие профили клиента остаются доступными.

Для запуска сразу с локальным профилем используйте
[Start-Local-LLM.cmd](../../Start-Local-LLM.cmd). Он прогревает Ollama и запускает
обычный исполняемый файл с изолированными настройками и историей. Нужны Go,
Ollama и загруженная модель; при отсутствии модели launcher скачивает её.

В [TUI](../../projects/deepseek-client/tui.go) название модели отображается над
каждым новым ответом, профиль и модель также видны в нижней панели настроек.
История диалога сохраняется существующим JSON store. Специального режима запуска
для локальной модели нет: используется штатное переключение API-профилей.

Проверочный прогон использует загрузчик обычной конфигурации, штатную команду
выбора профиля, TUI submit, agent, `askDeepSeek` и реальную Ollama. В записи
работает настоящий BubbleTea event loop. Ввод автоматизирован, временная
оболочка добавляет подписи этапов. Для демонстрации используется новая история
с публичными учебными вопросами; инструменты и RAG не подключены. Ответы не
подменяются и не проигрываются из готовых файлов.

Перезапуск в сценарии — повторная инициализация TUI и JSON store внутри процесса;
это не запуск нового процесса. Данные читаются с диска, что проверяет тест.

Все запросы генерации этих прогонов отправлены на loopback в локальную модель;
облачные модели и платные API не использовались. Обычный клиент позволяет
самостоятельно выбрать другой профиль. Это проверка локального профиля, без
изменения сетевых настроек компьютера.
