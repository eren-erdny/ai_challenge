# Структура DeepSeek Client

DeepSeek Client — приложение на Go с терминальным интерфейсом TUI и текстовым CLI. Оно поддерживает DeepSeek и другие OpenAI-compatible API, включая локальную Ollama.

## Основные части проекта

Пакет agent отвечает за подготовку запросов, цикл вызова инструментов, проверку ответов, инварианты и учёт токенов.
Файл agent_adapter.go связывает интерфейс приложения с агентом и поиском по базе знаний.
Файл tui.go реализует терминальный интерфейс. Файл session.go реализует текстовый сеанс и команды.
Пакет llm реализует HTTP-клиент для OpenAI-compatible chat completions.
Пакет knowledge управляет базами знаний, выбором базы для диалога и Python-процессом поиска.
Каталог rag-service содержит Python-пайплайн: чтение документов, разбиение, эмбеддинги, Qdrant и reranking.
Пакет mcptools подключает MCP-серверы и маршрутизирует имена SERVER__TOOL.
Пакет gitmcp предоставляет инструменты чтения Git-репозитория.
Пакет filetools предоставляет ограниченный доступ к файлам рабочей папки.
Пакеты history, memorylayers, taskstates, invariants и userprofiles хранят состояние пользователя.

## Где добавлять инструмент

Описание и реализация локальных файловых инструментов находятся в filetools/documents.go.
Общий интерфейс ToolExecutor и модельный цикл вызовов находятся в agent/tools.go.
Общая проверка вызовов перед исполнением находится в agent/tool_guard.go.
Регистрация Git MCP-инструментов находится в gitmcp/server.go.
Маршрутизация нескольких MCP-серверов находится в mcptools/registry.go.
Новый инструмент чтения для /help требует явного добавления в разрешённый список readOnlyTool.

## Границы репозитория

DeepSeek Client находится в projects/deepseek-client внутри монорепозитория AI Challenge.
Git-ветка относится ко всему монорепозиторию. Рабочая папка файловых инструментов в режиме помощника ограничена projects/deepseek-client.
Текущую ветку нельзя определять по этой документации: её нужно получать заново через MCP.
