# API и команды помощника разработчика

## Команда /help

/help без вопроса показывает локальную справку по командам.
/help Как устроен проект? запускает поиск по выбранной базе знаний и ответ модели в режиме только чтения.
В привязанном режиме проекта каждый вопрос /help получает свежий git_status через локальный MCP.
Документация и текущий MCP-контекст имеют разные источники цитирования.
Сбой обязательного Git MCP или отсутствие выбранной базы останавливают запрос до обращения к модели.
/tools off отключает инструменты и блокирует вопросы /help до включения /tools on.

## Git MCP

Локальный транспорт builtin-git запускает встроенный MCP-сервер по stdio.
Сервер читает один настроенный Git-репозиторий. Произвольный shell не запускается.
git_status возвращает ветку и изменённые пути.
git_log возвращает недавние коммиты.
git_diff возвращает изменения.
git_branches возвращает список веток.
Основной агент видит эти имена с префиксом git__: git__git_status, git__git_log, git__git_diff и git__git_branches.
Источник mcp://git/git_status содержит актуальный контекст ветки, полученный перед текущим ответом.

## Защита вызовов

Каждый предложенный моделью вызов проверяется до исполнения: известное имя, JSON Schema параметров и правила доступа.
JSON-параметры должны быть одним объектом без повторяющихся ключей.
Режим /help разрешает только явный список инструментов чтения. Запись файлов запрещена.
При активных инвариантах выполняется отдельная LLM-проверка каждого допустимого вызова.
Ошибка обязательного проверяющего блокирует действие. Уже выполненные действия не откатываются.
Описание MCP-инструмента само по себе не предоставляет разрешений.

## Запуск и обновление

Из корня монорепозитория запустите Start-Developer-Assistant.ps1.
При первом запуске индексируются README.md проекта и папка projects/deepseek-client/docs.
Параметр -PrepareOnly готовит индекс и проверяет MCP без вызова модели.
После изменения документации используйте -Rebuild для новой версии индекса.
Параметры -Python и -ModelCache указывают на готовое локальное RAG-окружение и кэш моделей.
Историческая docs/llm-wiki в корне монорепозитория не входит в корпус помощника.
