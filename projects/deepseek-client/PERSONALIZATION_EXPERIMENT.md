# Эксперимент персонализации

Цель — отправить один вопрос с разными профилями и проверить автоматическое
применение стиля, формата и ограничений. Используйте один API-профиль, модель,
temperature и режим.

## Подготовка

```text
/mode free
/temperature 0
/tools off
/persona create concise
Кратко и делово
Markdown, максимум три пункта
Не использовать emoji

/persona create teacher
Доброжелательно, объяснять новичку
Пошагово, с одним простым примером
Расшифровывать технические термины
```

Три строки после каждой команды `create` — ответы мастеру на вопросы о стиле,
формате и ограничениях. Несколько ограничений разделяются `;`.

## Сравнение

Выберите первый профиль и задайте вопрос:

```text
/persona use concise
Объясни, зачем приложению кэш.
```

Затем откройте новый диалог, выберите второй профиль и повторите дословно:

```text
/new
/persona use teacher
Объясни, зачем приложению кэш.
```

Сравните длину, структуру, тон, наличие примера, объяснение терминов и emoji.
Команда `/persona show` должна показывать настройки, но в сам вопрос их повторять
не нужно: активный профиль подставляется автоматически.

Автоматические тесты используют локальный синтетический клиент. Они проверяют,
что два профиля приводят к разным ответам, а один профиль присутствует в каждом
вызове режима compare. Для оценки поведения реальной модели нужен отдельный
live-прогон с разрешением и лимитом.
