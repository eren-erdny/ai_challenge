# DeepSeek Client

## Сохранение диалога

В режимах `free` и `controlled` переписка автоматически сохраняется и
восстанавливается после перезапуска, включая контекст для модели и текст в
интерфейсе. Файл: `conversations/default.json` рядом с пользовательским
`config.json` (Windows: `%APPDATA%/deepseek-client`, Linux:
`${XDG_CONFIG_HOME:-~/.config}/deepseek-client`). Ключи API в него не записываются.

Проверка: запустите `go run ./projects/deepseek-client` из корня репозитория,
введите `/mode free`, затем «Мой проект называется Север, бюджет 75000 рублей».
Дождитесь ответа, выйдите через `/exit`, запустите клиент снова и спросите
«Как называется мой проект и какой у него бюджет?».

История не зашифрована. При смене API-профиля она будет передаваться выбранному
провайдеру. Используйте один экземпляр клиента; `/clear` очищает только экран.
Режимы benchmark и compare изолированы от памяти. Подробнее:
[архитектура и ограничения памяти](agent/README.md#память).

Интерактивный Go-клиент DeepSeek и других OpenAI-compatible API с полноэкранным TUI, многострочной вставкой,
настраиваемой температурой, стратегиями промпта и режимами свободного,
контролируемого и сравнительного ответа. Программа работает до команды `/exit`.

Выполнение запросов выделено в независимый пакет `agent`. Он принимает запрос
через `Agent.Run(ctx, request)` и возвращает ответы, проверки, метрики и итог
судьи. Пакет `llm` реализует HTTP-клиент; TUI и CLI отображают полученный результат.
Архитектура, пример подключения и подготовка к памяти описаны в
[документации агента](agent/README.md).

## Эксперимент hw2

В режиме `compare` для одного пользовательского сообщения выполняются два вызова API:

1. Без ограничений: только исходное пользовательское сообщение.
2. С ограничениями из пользовательского `config.json`. По умолчанию это
   Markdown-формат с кратким абзацем и тремя пунктами, не более 80 слов,
   `max_tokens: 200` и `stop: ["<END>"]`.

DeepSeek не включает stop-последовательность в возвращаемый текст. Программа
показывает оба ответа и сравнивает количество слов, символов, токенов и значение
`finish_reason`. После второго ответа локальный судья проверяет, соблюдены ли
настройки. Дополнительный API-запрос для этой проверки не выполняется. В режимах
`free` и `controlled` каждый вопрос расходует только один API-запрос.

## Первый запуск

Если переменные `OPENAI_API_KEY` и `DEEPSEEK_API_KEY` не установлены и конфигурации ещё нет,
программа попросит ввести токен. В интерактивном терминале введённые символы
не отображаются.

```text
API-токен не найден.
Он нужен для выбранного OpenAI-compatible API.
Введите API-токен:
```

Введённый токен используется только в памяти процесса и не записывается в файл.
Для следующих запусков задайте переменную окружения, указанную в `api_key_env`.
Конфигурация без секретов создаётся вне репозитория:

```text
Windows: %AppData%\deepseek-client\config.json
Linux:   $XDG_CONFIG_HOME/deepseek-client/config.json
         или ~/.config/deepseek-client/config.json
```

На Linux каталог получает права `0700`, а файл — `0600`. На Windows файл
наследует ACL пользовательской папки AppData.

## Настройки ответа

Пример полного файла находится в `config.example.json`. Пользовательская
конфигурация имеет следующий формат:

```json
{
  "active_profile": "deepseek",
  "profiles": {
    "deepseek": {
      "base_url": "https://api.deepseek.com/v1",
      "api_key_env": "DEEPSEEK_API_KEY",
      "model": "deepseek-v4-flash"
    },
    "local": {
      "base_url": "http://127.0.0.1:1234/v1",
      "api_key_env": "",
      "model": "local-model"
    }
  },
  "generation": {
    "temperature": 0.7,
    "strategy": "standard"
  },
  "response_control": {
    "enabled": true,
    "format": "structured_markdown",
    "max_words": 80,
    "max_tokens": 200,
    "stop_sequences": ["<END>"]
  }
}
```

`generation.temperature` принимает значение от `0` до `2`. Низкие значения
дают более стабильные ответы, высокие увеличивают вариативность. Доступные
стратегии:

| Значение | Поведение |
|---|---|
| `standard` | Исходный запрос без дополнительной стратегии |
| `step_by_step` | Пошаговое решение с проверкой результата |
| `experts` | Отдельные мнения аналитика, инженера и критика, затем общий итог |

Для профиля `api.deepseek.com` клиент автоматически отправляет `"thinking":{"type":"disabled"}`. У V4 thinking-режим
включён по умолчанию, в нём `temperature` не применяется, а небольшой
`max_tokens` может целиком уйти на скрытое рассуждение и оставить финальный
`content` пустым.

Доступные текстовые модели:

| Значение | Назначение |
|---|---|
| `deepseek-v4-flash` | Быстрая универсальная модель, используется по умолчанию |
| `deepseek-v4-pro` | Более мощная модель для сложных задач |

Список соответствует текстовым моделям Chat Completions из официальной
[документации DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/).
Для другого OpenAI-compatible API имя модели не ограничено этим списком: задайте
его в `profiles.<name>.model` или командой `/model NAME`.

## Локальная OpenAI-compatible модель

Для LM Studio, Ollama с OpenAI-compatible маршрутом, LocalAI, vLLM и похожих
серверов укажите их базовый URL `/v1`. Клиент самостоятельно добавит
`/chat/completions`. Пример конфигурации без авторизации:

```json
{
  "active_profile": "local",
  "profiles": {
    "deepseek": {
      "base_url": "https://api.deepseek.com/v1",
      "api_key_env": "DEEPSEEK_API_KEY",
      "model": "deepseek-v4-flash"
    },
    "local": {
      "base_url": "http://127.0.0.1:1234/v1",
      "api_key_env": "",
      "model": "имя-модели-на-локальном-сервере"
    }
  },
  "generation": {"temperature": 0.7, "strategy": "standard"},
  "response_control": {
    "enabled": false,
    "format": "structured_markdown",
    "max_words": 80,
    "max_tokens": 200,
    "stop_sequences": []
  }
}
```

Пустой `api_key_env` означает, что профиль не использует авторизацию. Если она
нужна, укажите, например, `"api_key_env": "OPENAI_API_KEY"`. Порт и имя модели
зависят от локального сервера. После изменения файла выполните `/reload`.

Доступные значения `format`:

| Значение | Формат ответа |
|---|---|
| `plain_text` | Связный текст с короткими абзацами |
| `short_answer` | Один короткий абзац без вступления |
| `bullet_list` | Маркированный список |
| `structured_markdown` | Краткий ответ и ровно три пункта |
| `json` | JSON с полями `summary` и `points` |
| `custom` | Инструкция из поля `custom_instruction` |

Встроенный справочник можно посмотреть без токена и API-запроса:

```powershell
go run . --list-formats
go run . --list-models
```

Для собственного формата:

```json
{
  "response_control": {
    "enabled": true,
    "format": "custom",
    "custom_instruction": "Сначала преимущества, затем недостатки и вывод",
    "max_words": 150,
    "max_tokens": 300,
    "stop_sequences": ["<END>"]
  }
}
```

Недостающие поля получают значения по умолчанию. `enabled: true` запускает сеанс
в режиме `controlled`, а `enabled: false` — в режиме `free`. Допускается до 16
непустых stop-последовательностей.

## Локальный судья

После получения контролируемого ответа программа проверяет:

- количество слов относительно `max_words`;
- `completion_tokens` относительно `max_tokens`;
- структуру выбранного встроенного формата;
- `finish_reason` при настроенной stop sequence.

Для `structured_markdown` проверяются два обязательных заголовка и ровно три
пункта. Для `json` проверяется валидный JSON, непустой `summary` и массив `points`.
Формат `custom` нельзя универсально проверить локально, поэтому эта проверка
отображается как `INFO` и не влияет на общий результат.

Значение `finish_reason=stop` подтверждает корректную остановку, но DeepSeek не
сообщает, была ли это естественная остановка или конкретная stop sequence.

## Переменные окружения

Переменные окружения имеют приоритет над файлом. Они удобны для разработки и
автоматического запуска.

PowerShell:

```powershell
$env:DEEPSEEK_API_KEY = "ваш_токен_deepseek"
go run .
```

Для любого OpenAI-compatible API:

```powershell
$env:OPENAI_BASE_URL = "http://127.0.0.1:1234/v1"
$env:OPENAI_API_KEY = "токен_если_он_нужен"
go run .
```

Linux:

```bash
DEEPSEEK_API_KEY="ваш_токен_deepseek" ./deepseek-chat
```

`OPENAI_BASE_URL`, `OPENAI_MODEL` и `OPENAI_API_KEY` позволяют временно
переопределить активный профиль. Без такого переопределения клиент читает токен
только из переменной, указанной в `api_key_env` профиля.

Не добавляйте настоящий токен в `main.go`, `.env`, README или другие файлы
репозитория. `config.example.json` намеренно не содержит токен.

## Запуск

```powershell
go run .
```

При запуске в обычном терминале открывается TUI. Можно вставить через буфер обмена
текст с любым количеством строк и пустых абзацев. Вставленный текст целиком
остаётся в поле ввода. Интерфейс разделён горизонтально: окно «Диалог» находится
сверху, а окно «Ввод и настройки» — снизу на всю ширину терминала. История
занимает до тридцати двух строк и прокручивается только внутри верхнего окна, поэтому
новые сообщения не перемещают composer и настройки.

Клавиши TUI:

```text
Enter             отправить весь запрос
Ctrl+J/Alt+Enter  добавить перенос вручную
Tab/Enter         подставить выбранную команду или значение
↑/↓               выбрать вариант автодополнения
Колесо/PgUp/PgDn  прокрутить историю в окне «Диалог»
Esc/Ctrl+C        завершить программу
```

Автодополнение включается, когда поле ввода начинается с `/`. Оно подсказывает
команды, модели, режимы, стратегии, температуры и форматы. После подстановки
готовой команды нажмите `Enter` ещё раз, чтобы выполнить её.

Каждый вопрос независим: история предыдущих сообщений в API не передаётся.
Если stdin или stdout перенаправлен, используется совместимый построчный режим.

Команды интерактивного режима:

```text
/mode free         один запрос без ограничений
/mode controlled   один запрос с ограничениями и локальным судьёй
/mode compare      два запроса и сравнение результатов
/mode temperature_benchmark  три коротких ответа при temperature 0, 1.2 и 2
/mode model_benchmark  сравнить DeepSeek Flash, DeepSeek Pro и Ollama Cloud
/strategy standard обычный запрос без дополнительной инструкции
/strategy step_by_step  пошаговое решение с проверкой
/strategy experts  аналитик, инженер и критик формируют общий ответ
/temperature 0.7   изменить temperature в диапазоне от 0 до 2
/profile local     переключить профиль API и его модель
/profiles          показать все настроенные профили
/model deepseek-v4-flash  выбрать любую модель API для следующих запросов
/models            запросить список через стандартный GET /v1/models
/format NAME       изменить формат в памяти до закрытия программы
/formats           показать справочник форматов
/settings          показать активные настройки
/status            показать токены, стоимость и скорость последнего API-запроса
/reload            перечитать пользовательский config.json
/clear             очистить историю TUI
/help              показать помощь
/exit              завершить программу
```

В режиме `temperature_benchmark` каждый введённый запрос отправляется три раза с
одинаковым компактным профилем: до 120 слов и `max_tokens=300`, без длинного
вступления. Одинаковыми остаются модель и стратегия, а меняется только
`temperature`: `0`, `1.2`, `2`. После ответов выводится короткая сводка по длине,
токенам, времени, скорости и доле уникальных слов. Затем четвёртый запрос при `temperature=0`
передаёт модели все результаты: она сравнивает точность, креативность,
разнообразие и полезность, объясняет отличия и рекомендует подходящие задачи для
каждой температуры. Итоговый анализ ограничен 250 словами и `max_tokens=500`.
Этот режим расходует токены четырёх API-запросов.

В режиме `model_benchmark` исходный запрос без изменений отправляется в
`deepseek-v4-flash`, `deepseek-v4-pro` и модель профиля `ollama_cloud`. Все три
запроса наследуют текущие `temperature`, стратегию и настройки формата. Собственных
ограничений на модельные ответы этот benchmark не добавляет. Чтобы отправить
запросы без response-control, сначала выполните `/mode free`, затем
`/mode model_benchmark`. Чтобы применить выбранный формат и лимиты, используйте
`/mode controlled`, настройте `/format`, а затем включите `model_benchmark`.
После уже показанного пользовательского сообщения клиент выводит блоки
`модель: ответ` и сводку по токенам, скорости, времени и стоимости, не повторяя
исходный запрос.
Четвёртым запросом `deepseek-v4-pro` сравнивает качество ответов и формирует
рекомендации. Перед запуском должны быть заданы `DEEPSEEK_API_KEY` и
`OLLAMA_API_KEY`.

Изменения через `/format`, `/strategy`, `/temperature`, `/profile` и `/model` действуют
только в текущем сеансе. Для постоянного изменения отредактируйте
пользовательский `config.json`.

После редактирования файла выполните `/reload`, чтобы применить изменения без
перезапуска программы. Команда проверяет конфигурацию и не выводит токен. Токен
повторно используется только если endpoint не изменился.

## Сборка

Windows:

```powershell
go build -o deepseek-chat.exe .
```

Linux:

```bash
go build -o deepseek-chat .
```

Для сборки Linux-версии из PowerShell:

```powershell
$env:GOOS = "linux"
$env:GOARCH = "amd64"
go build -o deepseek-chat-linux-amd64 .
Remove-Item Env:GOOS
Remove-Item Env:GOARCH
```

После сборки установленный Go для запуска готового файла не требуется.

## Безопасность

Токены не записываются в `config.json` и не должны попадать в Git. Клиент читает
секрет активного профиля из указанной переменной окружения и передаёт его только
в заголовке `Authorization: Bearer`. Для удалённых API используйте только HTTPS;
HTTP допустим для локального loopback-сервера.

Пример вывода:

```text
DeepSeek Client
Вставьте многострочный запрос и нажмите Enter.

┃ Что такое интерфейс в Go?

Настройки
Модель: deepseek-v4-flash
Режим: controlled
Стратегия: standard
Temperature: 0.7
Формат: structured_markdown

Вы
Что такое интерфейс в Go?

DeepSeek
Интерфейс в Go — это набор сигнатур методов, описывающий требуемое поведение.

Метрики: model=deepseek-v4-flash, 14 слов, 92 символа, 25 токенов, 18.4 ток/с, 1.36 с, finish_reason=stop
Проверка ограничений: OK
```

`ток/с` — средняя скорость генерации: число `completion_tokens`, возвращённое
API, делённое на полное время HTTP-запроса. Так как клиент использует ответ без
стриминга, в это время входит и ожидание первого токена.

Команда `/status` отдельно показывает входные, кэшированные, выходные и общие
токены последнего API-вызова, его длительность, скорость в `token/sec` и
расчётную стоимость в USD. Расчёт доступен для известных моделей DeepSeek и
Ollama Cloud; для неизвестной модели клиент сообщает, что цена недоступна.
Тарифы могут меняться, поэтому итоговый счёт провайдера является источником
фактической стоимости.
