# Temperature Lab

Эксперимент сравнивает ответы DeepSeek на один и тот же пользовательский запрос
при трёх значениях параметра:

- `temperature = 0`;
- `temperature = 0.7`;
- `temperature = 1.2`.

Четвёртый API-запрос при `temperature = 0` сравнивает три ответа по точности,
креативности и разнообразию, после чего формулирует рекомендации для каждого
значения. Текст трёх исходных запросов полностью одинаков.

## Запуск из корня monorepo

```powershell
go run ./projects/temperature-lab
```

Введите запрос. Одна пустая строка может разделять абзацы, а две пустые строки
подряд завершают ввод. Перед обращением к API программа сообщает о четырёх
запросах и просит подтверждение.

Токен читается из `DEEPSEEK_API_KEY` или общей конфигурации:

```text
Windows: %AppData%\deepseek-client\config.json
Linux:   ~/.config/deepseek-client/config.json
```

Если токен не найден, программа скрыто запросит его только для текущего запуска.

## Тесты

```powershell
go test ./projects/temperature-lab/...
```

Тесты используют подменённый API и не расходуют токены.
