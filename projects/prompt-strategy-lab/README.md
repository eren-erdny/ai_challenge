# Prompt Strategy Lab

Эксперимент с четырьмя способами решения одной алгоритмической задачи через
DeepSeek API:

1. Прямой ответ без дополнительных инструкций.
2. Та же задача с инструкцией «решай пошагово».
3. Модель сначала составляет самостоятельный промпт, затем решает задачу по нему.
4. Аналитик, инженер и критик дают отдельные решения и общий итог.

Задачу пользователь вводит после запуска. Можно также указать известный
эталонный ответ. После четырёх решений отдельный API-судья сравнивает ответы с
эталоном и называет наиболее точный метод. Если эталон не задан, судья сначала
решает задачу самостоятельно. Всего выполняется 6 API-запросов.

## Запуск из корня monorepo

```powershell
go run ./projects/prompt-strategy-lab
```

Сначала введите задачу. Поддерживаются несколько строк и пустые строки между
абзацами. Две пустые строки подряд завершают ввод, поэтому после последней строки
дважды нажмите Enter. Затем таким же способом можно ввести эталонный ответ или
дважды нажать Enter, чтобы пропустить его. Неразрывные пробелы из скопированного
текста нормализуются.

Перед обращением к API программа показывает введённые данные и просит подтверждение:

```text
Будет выполнено 6 API-запросов: 4 решения, генерация промпта и сравнение.
Продолжить? [y/N]:
```

Только `y` или `да` запускает эксперимент; Enter отменяет его без расходов.

Программа использует `DEEPSEEK_API_KEY` или токен из общей пользовательской
конфигурации DeepSeek-клиента:

```text
Windows: %AppData%\deepseek-client\config.json
Linux:   ~/.config/deepseek-client/config.json
```

Если токен не найден, он запрашивается скрытым вводом только для текущего запуска.
